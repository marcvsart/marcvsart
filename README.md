# marcvs.art

O marcvs.art agora leva ao site unificado, na página Marcvs em inglês: **https://marcuscouto.com/en/art/** (o botão PT | EN leva à versão em português).

Este repositório só publica as páginas de redirecionamento do domínio (GitHub Pages, `CNAME` = `marcvs.art`). Cada endereço antigo leva ao equivalente novo e preserva a âncora:

| marcvs.art | marcuscouto.com |
|---|---|
| `/` | `/en/art/` |
| `/portraits-of-the-basilisk.html`, `/cryptoart.html`, `/imagem.html`, `/visuals.html` | `/en/art/#painting-cryptoart` |
| `/som.html` | `/en/art/sound/` |
| `/texto.html` | `/en/art/#literature` |
| `/bio.html` | `/en/` |
| `/films/*` | `/en/projects/zombiebasilisk/#films` |
| `/paintings/*` | `/en/art/#painting-cryptoart` |
| qualquer outro endereço | `/en/art/` (via `404.html`) |

O site anterior completo, com as pinturas em resolução original, está preservado na branch [`backup/antes-da-virada`](https://github.com/marcvsart/marcvsart/tree/backup/antes-da-virada).

O kit que gerou estas páginas está documentado em `docs/virada-marcvs-art/`, no repositório `marcvsart/marcuscouto-portfolio`.
